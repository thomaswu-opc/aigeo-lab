# 非实题用例：换「问谁」、换模型里的数值

> 由 `python try_cases.py` 生成。期望值不是抄来的：每例都由 `roomtruth.py` 从**当前这个模型**
> 重算（门洞用墙面覆盖法、方位用「右向=门洞墙→对面墙」「后向=开口→有墙」），与 agent 无关。

题面形状始终是第 01 题那一句，变的只是问谁、以及模型被改成什么样。

| 用例 | 期望（左右/净宽、前后/净深） | 实测 | 判定 |
|---|---|---|---|
| A 基准 · 问椅子 | 右 / 0.800，后 / 0.670 | 右 / 0.8，后 / 0.67 | 一致 |
| B 换对象 · 问窗框 | 右 / 2.500，后 / 3.150 | 右 / 2.5，后 / 3.15 | 一致 |
| C 换对象 · 问画框 | 右 / 4.860，后 / 1.170 | 右 / 4.86，后 / 1.17 | 一致 |
| D 换数值 · 椅子挪位 | 右 / 1.400，后 / 1.870 | 右 / 1.4，后 / 1.87 | 一致 |
| E 换单位 · mm | 右 / 0.800，后 / 0.670 | 右 / 0.8，后 / 0.67 | 一致 |
| F 换朝向 · 转 90° | 右 / 0.800，后 / 0.670 | 右 / 0.8，后 / 0.67 | 一致 |

判据分三层：数值（±2 cm）、标签（左/右、前/后）、**标签与带符号偏移是否自洽**。

`C` 例的轮次是一个单独的信号：语义范围收窄之前 96 轮（37 次 select 硬筛），收窄之后 51 轮且走了 `assembly`。
