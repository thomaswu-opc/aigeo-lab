# 泛化性矩阵

同一份任务卡、同一份 plan，只换模型。答案必须「跟着变换走」：距离不变、见证点随刚体变换移动、
尺度变则先由几何裁决单位再复原。

## 结论

- 4/4 个变体给出与原件一致的答案（偏差 < 1e-6 m），排序不变。
- 失败项是**预先声明的限制**：判据基于轴对齐包围盒，整体旋转 45° 后失效。
- 沙盒在失效时选择停止并报「证据不足」，而不是给出一个看似合理的错数。
