# 任务卡 · T-01-3

> 本卡是智能体在本次运行中收到的**全部**任务信息。卡内不含任何数值答案、不含对象编号、
> 不含解题步骤。运行开始时对卡做 SHA-256，写入账本首条记录。

## 题目原文（赛题 Task 01 第 3 问）

计算门扇所在平面与门所在墙面之间的较小夹角。

模型：房间（三面墙、地板、门洞和打开的门、窗户、画框，以及一张椅子）。

## 口径

- 「平面」由该实体的最大共面区域的**朝外法向**确定。
- 门扇是开着的，它的平面与门所在墙面不平行。
- 「较小夹角」取 0°–90° 之间的那个角：两条法向的夹角可能是钝角，需要取补角才对应
  两个平面的夹角。
- 角度以度为单位，保留 1 位小数。

## 输入

- 模型文件：`$MODEL`
- 格式未知、单位未知、朝向未知、对象编号与名称不可信。读取后须自行确认单位与朝向，
  并把依据写进结论。

## 输出要求

1. 夹角（°，1 位小数）。
2. 两条法向向量与它们的点积，用于复核这个角度。
3. 门扇、门洞、门所在墙面分别是哪三个实体，各自仅凭哪些几何量认定。
4. 若某一步几何证据不足，标为「未知」并说明缺什么，不要猜。

## 答案字段名

验收是机器读的，键名固定（键名不是答案，值怎么写仍按上面的要求）：

| 键 | 值 |
|---|---|
| `angle_deg` | 数，两条法向的较小夹角（°，1 位小数） |
| `dot` | 数，两条单位法向的点积 |
| `n_door` | `[x, y, z]`，门扇平面的单位法向 |
| `n_wall` | `[x, y, z]`，门所在墙面的单位法向 |
| `entities` | `{"door_leaf": 编号, "opening": 编号, "wall": 编号}` |
