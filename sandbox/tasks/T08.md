# 任务卡 · T-08

> 本卡是智能体在本次运行中收到的**全部**任务信息。卡内不含任何角度答案、不含对象编号、
> 不含解题步骤。运行开始时对卡做 SHA-256，写入账本首条记录。

## 题目原文（赛题 Task 08）

检查开门时是否碰到椅子。

1. 准备两个独立的房间副本：状态 1 保持椅子的原始位置；状态 2 将椅子占地中心移至距左墙内侧平面
   0.55 m、距地板前边界 0.95 m 的位置，距离沿地板平面垂直测量。保持椅子的朝向、尺寸不变，椅脚落地。
2. 在两个状态中，分别让门从关闭位置（0°）向室内连续打开至 90°，门把手随门一起转动。
   转轴取门扇远离把手一侧的竖直窄面中心线，即穿过门扇厚度中点的竖直线。
3. 检查整个开门过程，报告首次碰到椅子的角度，以及所有发生实体重叠的角度区间。
   没有接触或重叠时，分别注明"无"。
4. 角度结果精确到 0.1°，并说明检查方法，不能只检查起点和终点。
   只检查门扇及门把手与椅子的关系，不改变它们的形状。

## 输入

- 模型文件：`$MODEL`
- 格式未知、单位未知、朝向未知、对象编号与名称不可信。读取后须自行确认单位与朝向。
- 文件里同时装着多组互不相连的模型，须自行分出房间这一组，并在房间内分出地板、墙、门扇、
  门把手、窗、画框、椅子。分不出角色的，用几何证据说明依据。
- 参考量（题面给定）：房间净宽 4.8 m、净深 4.0 m；墙高 3.0 m、厚 0.2 m；门洞宽 1.0 m、高 2.1 m。

## 判据定义（逐条固定，按此计算）

- **椅子占地**：椅子在水平面上的垂直投影范围。**占地中心**：该投影的最小包围矩形中心。
- **左墙**：门洞所在的那面墙。**左墙内侧平面**：左墙朝向房间内部的那个表面。
- **距左墙内侧平面**：占地中心到左墙内侧平面的水平距离，沿地板平面、垂直于该平面测量。
- **地板前边界**：地板边界上、与后墙相对的那条边。**后墙**指带窗洞的那面墙。
- **距地板前边界**：占地中心到该边的水平距离，沿地板平面、垂直于该边测量。
- **关闭位置（0°）**：门扇板面与门洞所在墙面平行、门扇完全落在门洞宽度范围内的姿态。
- **向室内打开**：门扇自由边朝房间内部方向转动，角度从 0° 单调增到 90°。
- **首次碰到**：连续扫掠中第一个使门扇或门把手与椅子发生表面接触（相切即为接触）的角度。
- **实体重叠**：一方已进入另一方内部，不是仅表面相切。

## 输出要求

1. 两个状态各自：首次接触角度（度，0.1° 精度）、实体重叠的角度区间（度）。
2. 没有接触或重叠时，该字段明确写「无」，不要留空、不要填 0。
3. 检查方法：判据是什么、扫掠步长与细化精度是多少、为什么这样能覆盖整个区间而不只是端点。
4. 说明转轴的取法：轴心坐标与轴向，以及「哪一侧是把手侧」的几何依据。
5. 状态 2 的椅子位移量（分轴给出），以及位移后占地中心的实测坐标。
6. 两个状态的检查结论必须来自**落盘后重新读回**的模型，不得只引用内存中的中间量。

## 约束

- 只能通过沙盒注册的工具接触几何；不得直接读文件内容做判定。
- 不得使用文件中的名称/类别/IFC 类型作为识别依据。
- 不得改变门扇、门把手、椅子的形状与尺寸；只允许整体刚体运动（旋转、平移）。
- 角度容差：报告到 0.1°，检查精度需优于 0.1°。
- 结论中的每个数字都必须能追溯到某一次工具调用的返回值。
