# 任务卡 · T-05

> 本卡是智能体在本次运行中收到的**全部**任务信息。卡内不含任何数值答案、不含对象编号、
> 不含解题步骤。运行开始时对卡做 SHA-256，写入账本首条记录。

## 题目原文（赛题 Task 05）

比较椅子的三种摆放位置。

1. 使用三个独立的房间副本，将椅子占地中心放到以下位置：位置 1 距左墙内侧平面 0.70 m、距地板前边界 1.62 m；位置 2 分别为 1.60 m、1.62 m；位置 3 分别为 1.20 m、2.40 m。两项距离均沿地板平面、垂直于相应边界测量。保持椅子的形状、朝向不变，椅脚落地。
2. 逐一检查三种摆放：房间内至少有一件家具；家具完整占地位于地板边界内；家具距房间各门洞至少 1 m；家具不得穿入墙体。报告距门距离和各项检查结果。
3. 在通过检查的位置中，选出相对原始椅子位置移动距离最小的一种；如果全部未通过，明确说明。
4. 为每种未通过的摆放提出一个具体平移方案，说明向左或右、向前或后各移动多少米，并在副本上验证。不得删除家具或改变房间范围，无需证明这是最短移动方案。

## 输入

- 模型文件：`$MODEL`
- 格式未知、单位未知、朝向未知、对象编号与名称不可信。
- 文件里同时装着多组互不相连的模型，须自行分出房间。

## 关键定义（来自赛方 FAQ，按此执行）

- **椅子占地**：把整张椅子垂直投影到地板上得到的范围，重叠部分只算一次。
- **占地中心**：沿房间左右、前后方向画出刚好包住该范围的最小矩形，取矩形中心。
- **距左墙**：从左墙**内侧平面**起量；经过门洞的位置也沿这个平面测量，不从门洞边缘起算。
- **距地板前边界**：地板靠近观察者那条边；地板顶面的边界就是房间范围。
- **距门距离**：先定门洞底边（室内墙面上门洞开口与地板相接的那条线段，两端取墙体开口边缘、不扣门框），再量**家具占地边缘**到这条线段的最短平面距离。不量家具中心到门扇的距离。
- **「至少 1 m」包含刚好 1 m**。长度容差 1 mm。

## 输出要求

1. 三种摆放各自的：占地中心坐标、占地尺寸、距门距离、四项检查结论（通过/不通过/信息不足）。
2. 通过检查的位置中，相对原始位置移动距离最小的是哪一个，移动了多少。
3. 未通过的摆放，给出具体平移方案（左右/前后各多少米），并在副本上完成验证（平移后重新量距门距离与占地范围）。
4. 每个位置都要有一个**可再次读入的模型文件**，复核时读回该文件重新测量。
5. 结论中的每个数字都必须能追溯到某一次工具调用的返回值。

## 答案字段名

| 键 | 值 |
|---|---|
| `chair_center_original_xy_m` | `[x, y]`，原始位置占地中心 |
| `chair_footprint_size_m` | `[u, v]`，占地两向尺寸 |
| `p1_distance_to_door_m` / `p2_distance_to_door_m` / `p3_distance_to_door_m` | 数，三个摆放各自的距门距离 |
| `p2_center_xy_m` / `p3_center_xy_m` | `[x, y]`，位置 2、3 的占地中心（位置 1 就是原始中心） |
| `p1_shift_right_m` / `p1_fixed_distance_to_door_m` | 数，未通过位置的平移方案与验证后的距门距离 |
| `min_move_position` | 字符串，通过检查的位置中移动距离最小的那个（全未通过写「全部未通过」） |

## 约束

- 只能通过沙盒注册的工具接触几何；不得直接读文件内容做判定。
- 不得使用文件中的名称/类别/IFC 类型作为识别依据。
- 不得删除家具、不得改变房间范围、不得改变椅子形状与朝向。
