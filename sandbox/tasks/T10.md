# 任务卡 · T-10

> 本卡是智能体在本次运行中收到的**全部**任务信息。卡内不含任何角度与位移答案、不含对象编号、
> 不含解题步骤。运行开始时对卡做 SHA-256，写入账本首条记录。

## 题目原文（赛题 Task 10）

将火箭与发射台对接。

1. 根据三个插脚和凹槽的实际形状、位置，判断它们的对应关系，计算火箭需要的水平移动方向、距离，
   以及绕竖直轴转动的角度。
2. 将火箭所有部件作为一个整体移动和转动，保持火箭中轴线垂直于平台上表面。先在平台上方调整
   朝向和水平位置，再沿垂直于平台上表面的方向下降。不得缩放、修改接口或移动发射台。
3. 对接后三个插脚都应进入对应凹槽，火箭底部用于承托的表面与平台上表面接触，实体不得互相穿入；
   插脚不必碰到槽底。
4. 检查整个下降过程是否有实体穿插，允许最后到位时承托面接触。提交修改后的模型、最终移动方向和
   距离、旋转轴和角度，以及接口配合与碰撞检查结果，并说明参照位置。

## 输入

- 模型文件：`$MODEL`
- 格式未知、单位未知、朝向未知、对象编号与名称不可信。读取后须自行确认单位与朝向。
- 文件里同时装着多组互不相连的模型，须自行分出火箭与发射台这一组。
- 火箭各部件在文件中是一个整体实体；插脚与箭体可能焊在一起，拆不开时就只能在同一个实体上
  按高度分段观察截面。

## 判据定义（逐条固定，按此计算）

- **插脚**：从箭体底面沿轴向向下伸出的凸台。**插脚截面**：在该插脚高度区间内的水平截面轮廓。
- **凹槽**：平台上表面向下凹陷、底面为平面的坑。**凹槽截面**：凹槽底面上方的水平截面轮廓。
- **对应关系**：以插脚截面与凹槽截面的轮廓尺寸、形状为依据，不依据文件中的名称与编号。
  匹配应唯一；若两个候选的差异小于测量精度，须说明这一处无法唯一确定。
- **对接到位**：插脚底面高于或等于凹槽底面（允许悬空），同时火箭底部承托面与平台上表面接触。
- **实体穿插**：一方顶点进入另一方内部，不是仅表面接触。承托面与上表面的接触是允许的。
- **水平移动方向与距离**：在平台上表面的平面内，从火箭当前中轴线位置到对接位置的方向与长度。
- **转角**：绕竖直轴的旋转角，说明旋转中心与转向（右手定则）。
- **参照位置**：所有位移与角度都相对「火箭在文件中的原始位姿」给出。

## 输出要求

1. 三个插脚与三个凹槽的对应关系，逐个给出截面轮廓的长度尺寸与面积，以及配对依据。
2. 最终移动方向（单位向量）与水平距离（米）。
3. 旋转轴（方向向量）、转角（度，含符号与转向说明）、旋转中心坐标。
4. 下降方向与下降距离（米）。
5. 对接后三个插脚各自的落位检查：是否进入对应凹槽、与凹槽壁的最小间隙。
6. 整个下降过程的穿插检查结果：从哪个位置开始接触、接触性质（相切/穿插）、允许的接触位置。
7. 碰撞检查方法：判据、扫掠步长与细化精度；并说明为什么该判据能覆盖整个下降过程
   而不只检查起点和终点。
8. 提交修改后**可再次读入的模型文件**；检查结论须来自落盘后重新读回的模型。

## 答案字段名

| 键 | 值 |
|---|---|
| `pairing` | dict，三个插脚与凹槽的对应关系（插脚 → 凹槽） |
| `rotation_axis` | `[x, y, z]`，绕竖直轴的单位向量 |
| `rotation_angle_deg` | 数，绕该轴的转角（带符号时在 `rotation_angle_sign_note` 说明） |
| `rotation_pivot` | `[x, y, z]`，旋转中心 |
| `horizontal_shift_m` | `[dx, dy, dz]`，水平位移（z 恒为 0 或写下降前的 0） |
| `horizontal_distance_m` | 数，水平位移的模 |
| `fit_residual_max_m` | 数，对接后插脚与凹槽的最大配合残差 |
| `output_path` | 字符串，产物文件路径 |

## 约束

- 只能通过沙盒注册的工具接触几何；不得直接读文件内容做判定。
- 不得使用文件中的名称/类别/IFC 类型作为识别依据。
- 不得缩放任何部件，不得修改插脚或凹槽形状，不得移动发射台。
- 火箭所有部件必须作为整体运动：一次旋转、一次平移，不允许逐件摆位。
- 长度容差 1 mm；角度报告到 0.01°。
- 结论中的每个数字都必须能追溯到某一次工具调用的返回值。
