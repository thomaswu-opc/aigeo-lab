# 任务卡 · T-02

> 本卡是智能体在本次运行中收到的**全部**任务信息。卡内不含任何结论、不含对象编号、
> 不含解题步骤。运行开始时对卡做 SHA-256，写入账本首条记录。

## 题目原文（赛题 Task 02）

检查球与正方体的位置关系，以及椅子的接触情况。

1. 模型 A：将正方体围成的体积视为一个空间区域，保持球和正方体的尺寸不变。选定正方体的一面，
   从正方体中心沿垂直于该面、朝外的方向，分别将球心放在距离中心 0、0.25、0.75、2.25、2.75 m
   的位置。每种位置独立检查。
2. 模型 A：分别判断球与这个区域的关系，并用边界距离或球在区域内外的体积支持判断。
3. 模型 C：使用原始房间副本，检查椅子是否与地板、门扇或墙体发生面接触或实体重叠。
   仅有边、角接触不算面接触；接触也不等于实体重叠。

## 输入

- 模型文件：`$MODEL`
- 格式未知、单位未知、朝向未知、对象编号与名称不可信。读取后须自行确认单位与朝向。
- 文件里同时装着多组互不相连的模型（房间一组、球与正方体一组、火箭与发射台一组）。
  第 1、2 问只用「球与正方体」那组；第 3 问只用房间那组。

## 判据定义（逐条固定，按此计算）

- **空间区域**：正方体所围成的体积。区域的边界就是正方体的表面；判断「在内」「在外」
  都以这个表面为准。球与正方体都不许移动尺寸（第 1、2 问只移动球心）。
- **选定面**：由作答者自行选定正方体的一个面，并**在答案里说明是哪一面、外法向是什么**。
  一旦选定，五个位置都沿这一面的外法向排布，中途不得换面。
- **球心位置**：盒心 + d·(该面外法向)，d 取 0、0.25、0.75、2.25、2.75 m。
  每个位置单独判断，不继承前一个位置的结论。
- **边界距离**：球面到区域边界的最短距离，**带符号**：相切为 0，球在区域内或区域外
  而两者分离时为正，球越过边界时取负（负值即凸出/进入的深度）。
  只报球心到边界的距离是不够的 —— 那个量看不出相切。
- **球在区域内 / 区域的体积**：球与区域交集的体积。两者之和等于整球体积。
- **整球体积**：以拟合出的半径为据按 4/3·π·r³ 计算，不以题面标称值为据。
- **面接触**：两个实体有一段共同的表面，接触面积为正。**边接触、角接触** 的接触面积为 0，
  不算面接触。
- **实体重叠**：一方已进入另一方内部（存在穿入），不只是表面相切。

## 输出要求

1. 五个位置各一行：球心的 d 与坐标、关系名称、边界距离（带符号）、球在区域内与区域外的体积、
   占整球的比例。
2. 第 1 问里选的是哪一面、外法向是什么 —— 不给这一条，五个位置就无法复核。
3. 椅子与地板、门扇、每面墙：分别给接触面积与穿插判定（是否重叠、侵入深度）。
4. 明确写出哪些是「面接触」、哪些是「不接触」、哪些是「重叠」。
5. 每个数说明来源（哪一步、什么算法）；用体积和距离两个口径互相印证，不要只给一个。
6. 判据的容差（相切判定、共面容差）要写出来。

## 约束

- 只能通过沙盒注册的工具接触几何；不得直接读文件内容做判定。
- 不得使用文件中的名称、类别、IFC 类型、材质、属性作为识别或判定依据。
- 第 3 问只检查，不移动、不修改任何几何。
- 长度到 1e-4 m，面积到 1e-6 m²，体积到 1e-6 m³。
- 结论中的每个数字都必须能追溯到某一次工具调用的返回值；派生量同样要由工具算出。
