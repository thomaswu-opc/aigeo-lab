# 任务卡 · T-04

> 本卡是智能体在本次运行中收到的**全部**任务信息。卡内不含任何检查结论、不含对象编号、
> 不含解题步骤。运行开始时对卡做 SHA-256，写入账本首条记录。

## 题目原文（赛题 Task 04）

检查房间中的家具摆放。

1. 统计房间内的家具数量，检查是否满足「每个房间至少有一件家具」。当前模型只有一个房间，
   椅子算家具。
2. 检查每件家具的完整占地是否位于地板边界内，以及是否穿入墙体。
3. 测量每件家具到房间各门洞的距离，检查是否都至少为 1 m。距离按文末常见问题中的
   距门距离说明计算。
4. 分别对家具数量、占地范围、距门距离和穿墙情况给出「通过」「不通过」或「信息不足」，
   附测量值，并标出有问题的物体和位置。本题只检查，不移动或删除物体。

## 输入

- 模型文件：`$MODEL`
- 格式未知、单位未知、朝向未知、对象编号与名称不可信。读取后须自行确认单位与朝向。
- 文件里同时装着多组互不相连的模型。本题只用房间那一组。

## 判据定义（逐条固定，按此计算）

- **房间**：一块地板及其围合的墙体构成一个房间。房间数按地板的数量计。
- **家具**：房间内落地的独立可移动构件。门、窗、画框及其框架、玻璃、把手属于建筑构件，
  不算家具。判断依据只能是几何（落地、独立、尺寸、与建筑构件的连接关系），不得用名称或类别。
- **占地**：家具在水平面上的垂直投影范围。「完整占地位于地板边界内」指**这个投影范围**
  （不是三维包围盒）整体落在地板的水平范围内 —— 家具的高度当然会超出地板厚度，
  那不是越界。四条边都要有非负余量。
- **穿入墙体**：家具实体与任一墙体实体发生实体重叠（一方进入另一方内部）。
  表面贴合不算穿入。
- **距门距离**：家具占地边缘到门洞开口下沿那条线的**水平最短距离**。那条线是室内墙面上
  与地板相接的洞口下沿，两端取墙体开口边缘，不扣门框。不量中心到线段、不量三维表面距离。
- **至少 1 m**：距离 ≥ 1.000 m 为通过；小于 1 m 为不通过。容差 1e-3 m。

## 输出要求

1. 房间数、家具件数，以及「每个房间至少一件」的结论（通过 / 不通过 / 信息不足）。
2. 每件家具：占地范围与尺寸、四边到地板边界的最小余量、是否完整在地板内。
3. 每件家具：到每个门洞的距离（米）。有多个门洞时逐个给。
4. 每件家具：与每面墙的穿插判定（是否重叠、侵入深度）。
5. 四项总检查（数量 / 占地 / 距门 / 穿墙）各给结论词，并附支撑数值。
6. 有问题的物体：给编号、给位置（占地中心坐标）。没有问题时明确写「无」。
7. 判据容差要写出来；无法判断的项写「信息不足」并说明缺什么，不要用相近量顶替。

## 约束

- 只能通过沙盒注册的工具接触几何；不得直接读文件内容做判定。
- 不得使用文件中的名称、类别、IFC 类型、材质、属性作为识别依据。
- 本题只检查，不移动、不删除、不修改任何物体。
- 长度到 1e-4 m。
- 结论中的每个数字都必须能追溯到某一次工具调用的返回值。
