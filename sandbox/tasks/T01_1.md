# 任务卡 · T-01-1

> 本卡是智能体在本次运行中收到的**全部**任务信息。卡内不含任何数值答案、不含对象编号、
> 不含解题步骤。运行开始时对卡做 SHA-256，写入账本首条记录。

## 题目原文（赛题 Task 01 第 1 问）

以门洞中心在地板上的垂直投影为参照，报告椅子占地中心在其左侧还是右侧、前方还是后方，
并给出两个方向上的距离。

模型：房间（三面墙、地板、门洞和打开的门、窗户、画框，以及一张椅子）。

## 口径

- 房间的净宽、净深方向由**地板本身**定：地板在水平面内的长边方向是净宽，短边方向是净深。
  不要默认世界 x 就是净宽 —— 模型被整体旋转过时，这套方向随房间一起转。
  地板指纹里的 `h_long_axis` 就是「长边落在哪根世界轴上」，`h_long` / `h_short` 是两个边长；
  **不要用 `d0` 判这件事** —— `d0` 是排序后的最长边，不带轴名，房间一转它照样是 4.8，
  但它已经换了一根轴。两个方向的距离，取的是两个参照点**在对应那根轴上**的坐标差的绝对值。
- 「左/右」「前/后」是**相对门洞中心**说的，不是给椅子贴一个房间方位标签。先在房间里定出
  两根**有向**的轴，再比两个参照点沿这根轴的坐标：
  - **右向** = 沿净宽轴、从门洞所在那面侧墙指向它对面那面侧墙的方向。
    椅子沿右向的坐标比门洞中心大 ⇒ 椅子在门洞的**右侧**，距离 = 两者该轴坐标之差的绝对值。
  - **后向** = 沿净深轴、从开口侧（地板边缘上不贴墙的那一侧）指向有墙那一侧的方向。
    椅子沿后向的坐标比门洞中心大 ⇒ 椅子在门洞的**后方**，距离同样是该轴坐标差的绝对值。
  - 两根轴的方向都由房间自己定（门洞墙在哪、开口在哪），所以整个房间绕竖轴转多少度，
    右向/后向跟着一起转，判断结果不变。**不要用「世界坐标更大的那侧」代替它们。**
- 门洞中心：门洞开口在**墙面内**的矩形中心，沿竖直方向投影到地板顶面。
  在这份文件里，墙体开口可能本身就是一个独立的几何体（一个贯穿墙厚的盒），
  也可能是墙上缺掉一块、没有独立几何体 —— 以实际读到的为准，两条路都可以走。
  竖直方向的高度不参与本题的两个距离。`x`、`y` 两个分量必须取自**同一次**返回里的同一个点
  （例如同一条通底洞口的 center），不要把其中一个分量换成墙的包围盒中心。
- 文件里可能同时存在不止一组模型；本题只涉及其中那间房。
- 椅子占地中心：椅子在**水平面上的最小包围矩形**中心（用 `footprint` 取；
  不要用三维包围盒的中心 —— 椅子有靠背或扶手时，这两个点不是同一个点）。
- 两个方向上的距离，都是**沿该方向的投影距离**（不是两点的斜距）。

## 输入

- 模型文件：`$MODEL`
- 格式未知、单位未知、朝向未知、对象编号与名称不可信。读取后须自行确认单位与朝向，
  并把依据写进结论。

## 输出要求

1. 左右：左/右，以及沿净宽方向的距离（m，保留 3 位小数）。
2. 前后：前/后，以及沿净深方向的距离（m，保留 3 位小数）。
3. 两个参照点的坐标，并注明所依据的坐标系（世界轴，还是场景主参照系）。
4. 说明门洞与椅子分别是如何**仅凭几何**被识别出来的（不得使用名称、类别、材质、
   父子关系、自定义属性）。
5. 若某一步几何证据不足，标为「未知」并说明缺什么，不要猜。

## 答案字段名

验收是机器读的，键名固定（键名不是答案，值怎么写仍按上面的要求）：

| 键 | 值 |
|---|---|
| `door_center_floor_xy_m` | `[x, y]`，门洞中心在地板顶面的投影 |
| `chair_center_floor_xy_m` | `[x, y]`，椅子占地中心 |
| `left_right` | `"左"` 或 `"右"` |
| `offset_along_right_m` | 数，**带符号**：椅子中心沿右向的坐标 − 门洞中心沿右向的坐标 |
| `distance_width_m` | 数，沿净宽方向的投影距离（m，3 位小数） |
| `front_back` | `"前"` 或 `"后"` |
| `offset_along_back_m` | 数，**带符号**：椅子中心沿后向的坐标 − 门洞中心沿后向的坐标 |
| `distance_depth_m` | 数，沿净深方向的投影距离（m，3 位小数） |
| `coordinate_frame` | 字符串，说明坐标依据的是世界轴还是场景主参照系 |

`distance_width_m` 就是 `|offset_along_right_m|`，`distance_depth_m` 就是 `|offset_along_back_m|`
（同一个数的两种写法，不许各算一遍）。`left_right` 由 `offset_along_right_m` 的符号翻译而来
（正=右、负=左），`front_back` 由 `offset_along_back_m` 的符号翻译而来（正=后、负=前）。
两个偏移量都要走 `calc` 算出，别手写。

坐标一律给**世界轴**的米制值（若模型被整体旋转过，另在 `coordinate_frame` 里注明
房间自身的净宽/净深分别落在哪根轴上）。

## 约束

- 只能通过沙盒注册的工具接触几何；不得直接读文件内容做判定。
- 不得使用文件中的名称/类别/IFC 类型作为识别依据。
- 结论中的每个数字都必须能追溯到某一次工具调用的返回值。
