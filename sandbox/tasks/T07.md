# 任务卡 · T-07

> 本卡是智能体在本次运行中收到的**全部**任务信息。卡内不含任何数值答案、不含对象编号、
> 不含解题步骤。运行开始时对卡做 SHA-256，写入账本首条记录。

## 题目原文（赛题 Task 07）

对球与正方体的网格做两处编辑，两个编辑任务各自从原始模型副本开始。

1. 将边长 2.5 m 的正方体顶面提高 0.5 m，得到高 3.0 m 的长方体；底面位置、宽度和深度不变。
2. 沿距球最低点 0.5 m 的水平平面切除球的下部，保留上部，并用平面封闭切口。保留部分的曲面不变。
3. 提交编辑后的网格，检查是否封闭、是否有破洞或重复面，并报告编辑后的尺寸、体积和球的切口面积。

## 输入

- 模型文件：`$MODEL`
- 格式未知、单位未知、朝向未知、对象编号与名称不可信。读取后须自行确认单位与朝向，并把依据写进结论。
- 文件里同时装着多组互不相连的模型，须自行分出「球与正方体」这一组。

## 输出要求

1. 编辑后长方体的三个尺寸与体积；原始正方体的对应值一并给出（本题要求展示修改前后）。
2. 编辑后球的体积、表面积、切口面积；原始球的对应值一并给出。
3. 封闭性检查结果：是否封闭、破洞个数、重复面个数、退化面个数。
4. 「正方体的上下」若可任选一面为底，须说明所选取的底面。
5. 编辑结果必须是**可再次读入的模型文件**，并且复核时要读回该文件重新测量，不得只引用内存中的中间量。

## 答案字段名

| 键 | 值 |
|---|---|
| `cube_dims_before_m` / `cube_dims_after_m` | `[3]`，三边 |
| `cube_volume_before_m3` / `cube_volume_after_m3` | 数 |
| `ball_volume_before_m3` / `ball_volume_after_m3` | 数（网格体积） |
| `ball_area_after_m2` / `cut_area_m2` | 数，切顶后的表面积与切口面积 |
| `cube_closed` / `ball_closed` | 0/1，封闭性（`mesh_health` 的 closed） |
| `ball_boundary_loops` / `ball_duplicate_faces` | 整数，破洞与重复面计数 |

## 约束

- 只能通过沙盒注册的工具接触几何；不得直接读文件内容做判定。
- 不得使用文件中的名称/类别/IFC 类型作为识别或编辑依据。
- 长度容差 1 mm；球的网格量与理想球体比较允许 0.3% 相对误差。
- 结论中的每个数字都必须能追溯到某一次工具调用的返回值。
