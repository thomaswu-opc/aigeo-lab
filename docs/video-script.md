# 5 分钟演示视频 · 逐镜脚本

> 赛方要求：不超过 5 分钟，展示「所解决的问题、方法与结果」。评委看的是**方法与实现**，
> 不是产品宣传片。原则：每一段都让屏幕上的东西自己说话，旁白只补「为什么这样设计」。

录制建议：1920×1080，只录观测台与终端，不做动画特效；字幕写结论，别写「我们很努力」。

## 录制前检查

```bash
cd sandbox
bash reproduce.sh                      # 先生成 runs/（不入库，但录制要用）
python view.py export ag_ifc           # 若不想开服务，导出单文件页
python view.py                         # 观测台，录制主窗口
```

- 终端字号 ≥ 16pt；观测台窗口 ≥ 1440 宽，右侧画面才不被挤掉。
- 关掉通知；`runs/` 目录里会有大量历史目录，录制时只点 `ag_ifc`、`cmp_绕竖轴_45_`、`adv_gate`、`adv_fab`。
- 画面上不要出现本机绝对路径以外的个人信息；`runs/*/report.md` 里有绝对路径，介意就遮掉。

## 不要做的事

- 不要把「五变体全对」讲成「方法通用」—— 只证明了这一题的同类变化。
- 不要剪掉 RECOVER 那 2 轮：那是编排层有效性的唯一直接证据。
- 不要用「AI 自动建模」这类词：本作品做的是**几何推断与检查**，不生成几何。
